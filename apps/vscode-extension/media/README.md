# Extension media

`icon.png` is the Bremio mark: the four Bremen Town Musicians converging on one
point — a donkey, dog, cat and rooster, four different minds heading the same
way. That is the name's origin and the product's whole premise, so it is not
interchangeable with a generic lettermark.

VS Code shows this in the Extensions view and the marketplace. A square PNG of
at least 128x128 is required; larger is fine and scales down cleanly.
